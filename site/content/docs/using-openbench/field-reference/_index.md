This reference explains what to record and why. Examples use the seeded thermal experiment. Empty is
better than invented information: readiness can show a gap, while fabricated context cannot be
recovered later.

## Browse by task

- [Planning and design](planning-and-design/) — projects, questions, factors, conditions, and specimens.
- [Scientific record and method validation](scientific-record/) — sources, instruments, calibration, evidence, procedures, and assessments.
- [Executions and measurements](execution-and-measurements/) — runs, observation provenance, quality, missingness, and CSV import.
- [Analysis, review, and release](analysis-review-and-release/) — saved calculations, conclusions, review targets, decisions, and report status.
- [Audit and exports](audit-and-exports/) — version labels, revision boundaries, JSON exchange, archives, and reset behavior.

The [guided journeys](../guided-journeys/) show these fields in complete worked examples.
